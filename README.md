# Конвертер текста и азбуки Морзе

## Описание проекта

В рамках проекта был разработан веб-сервис на Go для автоматической конвертации обычного текста и азбуки Морзе.

Приложение предоставляет HTML-форму, через которую пользователь может загрузить текстовый файл. Сервис автоматически определяет содержимое файла: обычный текст или код Морзе, выполняет конвертацию в противоположный формат и сохраняет результат в новый локальный файл. После обработки пользователю возвращается преобразованный текст.

Проект демонстрирует работу с HTTP-сервером, обработкой HTML-форм, загрузкой файлов и взаимодействием с файловой системой.

---

## Архитектура проекта

Проект разделён на несколько пакетов, каждый из которых отвечает за отдельную часть приложения:

- `server` — создание и настройка HTTP-сервера;
- `handlers` — обработка HTTP-запросов;
- `service` — бизнес-логика определения и конвертации содержимого файла;
- `pkg/morse` — библиотека для преобразования текста в код Морзе и обратно.

Такое разделение позволило сделать код более понятным и соответствующим принципам многослойной архитектуры.

## Реализованный функционал

### Автоматическое определение содержимого файла

В пакете `service` реализована функция, которая автоматически определяет формат входных данных.

В зависимости от содержимого файла сервис:

- определяет, является ли текст кодом Морзе или обычным текстом;
- преобразует текст в код Морзе;
- либо преобразует код Морзе обратно в текст;
- обрабатывает возможные ошибки во время конвертации.

Для анализа содержимого используются возможности стандартной библиотеки Go.

---

### Отображение HTML-формы

Для корневого маршрута `/` реализован обработчик, который:

- возвращает страницу `index.html`;
- отображает форму для загрузки файлов;
- позволяет пользователю выбрать файл для обработки.

---

### Загрузка и обработка файлов

Для маршрута `/upload` реализован обработчик, который выполняет полный цикл обработки данных:

1. принимает HTML-форму;
2. получает загруженный пользователем файл;
3. считывает его содержимое;
4. передаёт данные в сервис определения формата;
5. получает результат конвертации;
6. создаёт новый локальный файл с уникальным именем;
7. сохраняет результат конвертации;
8. возвращает преобразованный текст пользователю.

Во всех этапах обработки предусмотрена обработка возможных ошибок с возвратом соответствующего HTTP-статуса.

---

### Настройка HTTP-сервера

В пакете `server` реализовано создание и настройка HTTP-сервера.

При запуске приложения:

- создаётся HTTP-роутер;
- регистрируются все обработчики;
- настраивается сервер на порту **8080**;
- задаются таймауты чтения, записи и ожидания соединения;
- подключается логгер для регистрации ошибок.
